Struttura delle Directory
La codebase è organizzata per separare nettamente le risorse grezze, i dati elaborati e i moduli logici:

Plaintext
OsteoGen/
├── imgs/                      # Dati originari grezzi (es. estratti dal file Versione 1)
├── data/
│   ├── raw/                   # Dati accoppiati e normalizzati (input_x/ e target_y/)
│   └── processed/             # Tensori finali 512x512 pronti per il dataloader
├── src/
│   ├── setup_raw.py           # Script di organizzazione file
│   ├── preprocess.py          # Pipeline visiva offline (Computer Vision)
│   └── dataset.py             # Classe PyTorch OsteoDataset
└── [train.py]                 # (Da implementare) Main loop per il training




Flusso di Lavoro e Moduli
1. Organizzazione dei Dati (src/setup_raw.py)

Scopo: Isolare le coppie di immagini (scheletro e tessuti) e uniformare la nomenclatura.

Funzionamento: Analizza la cartella imgs/. Identifica le immagini tramite i suffissi _ossa e _output, rimuove eventuali spaziature errate e copia i file nelle rispettive directory data/raw/input_x (condizione del modello) e data/raw/target_y (ground truth).

Allineamento: Garantisce che il file di input e il rispettivo target condividano esattamente lo stesso ID alfanumerico, un prerequisito rigido per il successivo accoppiamento a runtime.

2. Preprocessing Offline (src/preprocess.py)

Scopo: Standardizzare le immagini a livello geometrico e cromatico prima del training, evitando colli di bottiglia computazionali sulla CPU durante l'addestramento.

Inizializzazione Motore di Inferenza (Solo Primo Avvio): Durante la primissima esecuzione, lo script scarica automaticamente nella cache di sistema (.u2net\) il file u2net.onnx (circa 176 MB). Questo file contiene i pesi matematici pre-addestrati della rete neurale necessaria per il riconoscimento visivo dei soggetti. Il download avviene una sola volta.

Fasi della Pipeline:

Background Removal: Sfrutta rembg e il modello U^2-Net (supportato da onnxruntime) per eliminare lo sfondo e isolare esclusivamente l'anatomia del soggetto.

Auto-Cropping: Calcola la bounding box sui canali Alpha per eliminare lo spazio vuoto in eccesso.

Padding Simmetrico: Inserisce il soggetto al centro di una tela quadrata basata sul lato maggiore, prevenendo distorsioni anatomiche.

Resizing: Scala l'immagine a risoluzione 512x512 utilizzando il filtro di ricampionamento Lanczos per la massima conservazione dei dettagli.

Sfondo Neutro: Converte l'immagine in RGB con sfondo nero assoluto (0, 0, 0), facilitando il calcolo della loss (es. Perceptual Loss) sulle regioni vuote.

Validazione: Include un blocco assert finale che interrompe l'esecuzione se viene rilevata una discrepanza numerica tra i file in input_x e target_y.

3. Dataloading a Runtime (src/dataset.py)

Scopo: Fornire un'interfaccia compatibile con i DataLoader di PyTorch per alimentare la rete neurale iterativamente.

Funzionamento: Instanzia la classe OsteoDataset puntando alla directory data/processed.

Data Augmentation: Implementa trasformazioni spaziali (tramite albumentations) applicate in modo strettamente sincronizzato sia sulla X che sulla Y, mantenendo l'allineamento perfetto tra struttura ossea e posa dell'animale. Le alterazioni includono:

Riflessioni orizzontali.

Spaziamenti, rotazioni e scale minori.

Deformazioni elastiche, cruciali per simulare le varianze naturali dei tessuti biologici.

Normalizzazione: Mappa matematicamente i valori dei pixel nel range continuo [-1, 1] richiesto nativamente dai modelli generativi per una corretta convergenza dei gradienti.
